# TEC NOVA Sinaloa — Equipo 05

Landing page educativa para practicar la publicación de sitios estáticos con GitHub Pages.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: diseño adaptable, paleta TEC NOVA y animación de cohetes.
- `script.js`: menú móvil y efecto de despegue generado con Web Audio API.
- `assets/`: logotipos e identidad visual proporcionados.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo en GitHub.
2. Sube el contenido de esta carpeta (no es necesario subir el ZIP).
3. Verifica que `index.html` esté en la raíz del repositorio.
4. Ve a **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Selecciona la rama `main` y la carpeta `/(root)`, y guarda.
7. Espera la publicación y abre el enlace que GitHub Pages muestra en esa sección.

## Personalización
Edita los textos de `index.html`. Los colores principales están definidos al inicio de `styles.css` como variables CSS. El efecto de sonido se genera en el navegador; no necesita un MP3.

## Nota
El sitio carga la tipografía DM Sans y Space Grotesk desde Google Fonts. Si no hay conexión, se mostrarán tipografías de respaldo.
