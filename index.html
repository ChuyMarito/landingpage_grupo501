02 / CENTRO DE APRENDIZAJE

Tu primera página
en órbita.

No necesitas ser experto. Sigue estos pasos y convierte tus archivos en un sitio que cualquiera pueda visitar.

01
▤

Prepara tus archivos

Crea una carpeta para tu proyecto. Agrega tu archivo index.html, tus estilos styles.css y las imágenes que vas a utilizar.

TU PROYECTO
02
⌘

Crea un repositorio

Entra a GitHub, inicia sesión y selecciona New repository. Ponle un nombre, por ejemplo mi-primera-web.

GITHUB
03
⇧

Sube tu página

Dentro del repositorio, usa Add file → Upload files. Arrastra los archivos y confirma con Commit changes.

TUS ARCHIVOS
04
◎

Activa Pages

Abre Settings → Pages. En Build and deployment elige Deploy from a branch, selecciona main y /(root), y guarda.

PUBLICACIÓN
05
✦

¡Tu sitio está en línea!

Espera a que termine la publicación. GitHub Pages mostrará un enlace público para compartir tu página. Si haces cambios, súbelos al repositorio.

MISIÓN COMPLETADA
✦
Consejo de la tripulación

El archivo principal debe llamarse exactamente index.html y estar en la carpeta que seleccionaste para publicar.
